### **Why ZubZet?**

- **Start simple, grow to enterprise:** ZubZet has one principle: simple by default, more when you need it. Every lightweight tool has a heavier sibling for the day you outgrow it, and the two work together without breaking your project.

- **Zero config, full control when you need it:** Skip the boilerplate. Drop a controller into `app/Controllers/` and the URL exists. ZubZet’s pre-configured components allow you to prototype and develop your projects faster, while maintaining clean and structured code.

- **No Barriers for Newcomers:** We believe everyone should have access to good tools. ZubZet is welcoming, friendly, and empowers newcomers.

- **Great Portability:** Whether you're developing locally or deploying in a complex production environment, ZubZet is designed to be lightweight, flexible, and portable.

### **Enterprise essentials, built in**

- **Auto Form Validation:** Automate form validation with error reporting and database integration.
- **Authorization:** Manage roles and permissions with flexible access control, including wildcards.
- **Migrations & Query Builder:** Evolve your database schema with migrations and an expressive query builder.
- **File Uploads:** Handle file uploads with preset rules for type and size validation.
- **Email Integration:** Send emails directly from your application with customizable templates.
- **CLI Tooling:** Ship and operate your app with built-in console commands based on Symfony Console.

### **A Gentle Approach to MVC**

The framework follows the **Model-View-Controller** (MVC) pattern, but you don’t need to be an expert to get started:

1. **Controllers** handle application logic in a simple, straightforward way.
2. **Models** manage data interactions with minimal setup, be it a database or other sources.
3. **Views** are Blade templates with template inheritance and reusable components that integrate with your data.
